# Smart-Walker

Designed and developed a sensor-based smart walker for real-time monitoring of obstacles, user stability,
and potential falls.


Integrated HC-SR04 ultrasonic sensors for obstacle detection and MPU6050 IMU sensors for monitoring tilt
and detecting potential falls.


Implemented HX711 load cell amplifiers with load cells for real-time weight monitoring and buzzer/LCDbased alerts for immediate user feedback.
Integrated hardware and software components using Arduino Uno to provide real-time safety monitoring
and alert generation.
